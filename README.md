# gridgo-landing

The GRIDGO public landing site, served at **https://gridgo.talasora.com**.

Part of the GRIDGO fleet:

| Repo | What it is | Where it runs |
|---|---|---|
| `gridgo-landing` | Public landing site | `gridgo.talasora.com` |
| `gridgo-web` | Supplier / operations / admin dashboard | `gridgo-dash.talasora.com` |
| `gridgo-api` | Backend API for every client | `gridgo-api.talasora.com` |
| `gridgo-client` | Customer mobile app | Android release build |
| `gridgo-supplier` | Print shop mobile app | Android release build |
| `gridgo-rider` | Rider mobile app | Android release build |
